# Upgrade Path and Future Features

## Version Roadmap

### v1.0 (Current)
- Terminal command triggers
- Basic language detection
- Core conversion framework
- 5 target languages (Python, C, C++, Java, JS)

### v1.1 (Planned)
- Right-click context menu
- Improved language detection
- Better error messages
- Conversion quality improvements

### v1.2 (Future)
- TypeScript support
- Go language support
- Rust language support
- Batch file conversion

### v2.0 (Long-term)
- AI-powered conversion improvements
- Custom conversion rules
- Project-wide conversion
- Integration with build systems

## Extension Updates
- Automatic updates via VS Code marketplace
- Backward compatibility maintained
- New converters added incrementally
- User settings preserved across updates

## Migration Notes
- No breaking changes planned for v1.x
- Configuration files will be auto-migrated
- Custom converter modules will remain compatible
