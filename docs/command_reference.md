# Command Reference

## Terminal Commands

### Convert Code Language-python
Converts current file to Python
- **Target**: Python (.py)
- **Features**: Automatic indentation, Pythonic patterns
- **Example**: `Convert Code Language-python`

### Convert Code Language-c
Converts current file to C
- **Target**: C (.c)
- **Features**: Manual memory management, procedural style
- **Example**: `Convert Code Language-c`

### Convert Code Language-cpp
Converts current file to C++
- **Target**: C++ (.cpp)
- **Features**: Object-oriented patterns, STL usage
- **Example**: `Convert Code Language-cpp`

### Convert Code Language-java
Converts current file to Java
- **Target**: Java (.java)
- **Features**: Class structure, package organization
- **Example**: `Convert Code Language-java`

### Convert Code Language-js
Converts current file to JavaScript
- **Target**: JavaScript (.js)
- **Features**: Modern ES6+ syntax, functional patterns
- **Example**: `Convert Code Language-js`

## Command Aliases (Future)
- `ccl-python` → `Convert Code Language-python`
- `ccl-cpp` → `Convert Code Language-cpp`
- `ccl-java` → `Convert Code Language-java`

## Output Format
All conversions create new untitled tabs with:
- Conversion header comment
- Converted code content
- TODO markers for manual review areas
- Appropriate syntax highlighting
