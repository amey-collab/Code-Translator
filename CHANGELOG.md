# Changelog

All notable changes to the Kiro Code Translator extension will be documented in this file.

## [1.0.0] - 2025-12-25

### Added
- Initial release of Kiro Code Translator
- Terminal command-based conversion system
- Support for 5 programming languages (Python, C, C++, Java, JavaScript)
- Automatic source language detection
- Safe conversion (never overwrites original files)
- New tab output with syntax highlighting
- Comprehensive error handling
- Modular converter architecture for future expansion

### Features
- `Convert Code Language-python` command
- `Convert Code Language-c` command  
- `Convert Code Language-cpp` command
- `Convert Code Language-java` command
- `Convert Code Language-js` command
- Auto-detection of source language from code patterns
- File extension-based language hints
- TODO comment insertion for complex conversions
- Terminal error messaging for invalid commands

### Documentation
- Complete usage guide
- Error handling documentation
- Command reference
- Upgrade path planning
- Unsupported cases documentation
